# Painwood

A tiny bookmark for reading [Achewood](https://achewood.com) from the first strip (October 1, 2001) onward.

Open `index.html` in a browser, or turn on GitHub Pages for this repo (Settings → Pages → deploy from branch). Then:

- **Open this strip** takes you to the strip you're on.
- After reading, save the date of the last strip you read, or paste its URL. **Next day →** moves the bookmark forward one day.
- The reading log shows when you read and how far you got.

The bookmark is saved in your browser. To move it to another device, use **Copy backup code** and **Restore from code** under Settings. If Achewood changes its URL format, you can change the link pattern there too.
